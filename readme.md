# Galería Creativa

Este proyecto es una página web creada como práctica de CSS, donde trabajé un diseño con menú lateral, galería de imágenes y un footer. El objetivo fue aplicar Flexbox, Grid, media queries y animaciones simples para lograr una interfaz adaptable y visualmente coherente.

Puedes ver el proyecto en vivo aquí:

---

## Descripción

El sitio está pensado como una galería de imágenes donde se pueden visualizar distintas fotografías en formato grid. La página incluye un menú lateral con navegación básica y un footer con información de contacto.

Se aplicaron estilos CSS para lograr un diseño responsive y efectos visuales en las imágenes al interactuar con ellas.

## Funcionalidades

- Menú lateral con navegación
- Diseño responsive adaptable a dispositivos móviles
- Galería de imágenes en formato grid
- Efecto hover en imágenes (escala y cambio de filtro)
- Footer con información de contacto
- Diseño visual coherente y limpio
